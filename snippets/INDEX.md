# 叙事内容索引

本索引是 RENTAL 项目跨层叙事内容的统一视图。RENTAL 的叙事被拆分为三个层级，各自承担不同的职责，但共享同一套 canon 事实。本页不存放任何内容，只提供导航，所有跨层引用请以本页为入口。

- **L0 canon**：不可更改的世界设定基石。世界为什么是这样、四大阵营的立身之本、历史纪年与短篇小说。
- **L2 任务叙事**：玩家可承接的突袭任务、委托与目标叙事。围绕"搜—战—撤"核心循环展开。
- **L3 物品描述**：武器、道具、敌人的个体化文本，是 canon 在具体物件上的落点。
