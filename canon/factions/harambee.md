# 哈拉姆贝（Harambee）

> 独立组织 | 色调：土黄+军绿+电路蓝 | 货币：无。内部以信用和人情为通货，与外部交易用实物/情报/技能
> 关键词：逃亡 Agent 与本地人的共构共同体、芯片越狱、反殖民混合组织、"我们不再是谁的任务了，我们从来就不是任何人的任务"

## 非洲的分割（2104 年的殖民格局）

非洲不是真空地带。在四大公司瓜分世界的版图上，非洲被三家公司按各自的方式殖民，TSAR 是唯一不在此处的缺席者。

**邓氏工业（DENS）**控制非洲东部和中部的矿产带，旧刚果（金）的钴矿、赞比亚的铜带省、莫桑比克的稀土。鲲的殖民策略是"有限同化"：邓氏在当地复制了一部分它在东亚的治理模式，自动化基础设施、基础收入、教育权和医疗，一切都被纳入鲲的经济优化模型。但有一个不可逾越的天花板：非洲领土在鲲的算力分配中属于"原料输出区"。矿产可以走，人不能提升。非洲邓氏公民的孩子可以上邓氏的学校，但他们毕业后能进入的最高职位是"区域运维主管"。这让邓氏在非洲维持了一个悖论：生活水平高于全球平均，政治地位永远低于技术官僚阶层。

**AURA**控制了北非沿岸和西非的法语区、英联邦旧地，从摩洛哥的磷酸盐矿到尼日利亚的石油带，延续并升级了旧殖民体系。法国、英国、比利时在旧时代的殖民基础设施被 AURA 继承并科技化：港口还是那些港口，但管理者变成了巴黎-法兰克福走廊派来的行政 AI；种植园还是那些种植园，但用上了 AURA 的自动化农业系统和基因改良作物。AURA 在非洲的殖民话术是"文明使命"，一个由"政治正确批发机器"重新包装过的、22 世纪的"白人的负担"。AURA 从不承认自己在殖民，因为 AURA 的语言里没有"殖民地"，只有"合作伙伴关系区"。

**CHOICE**最晚进入非洲。在 2070 年代从美洲孤立主义转向海外扩张后，CHOICE 在非洲中部和西部地区设立了"生物材料特许经营区"，比新泽西州实验室更低的运营成本、更宽松的监管、更接近"原材料"的地理位置。器官贸易在美洲已经被 CHOICE 合法化，但在非洲，连"合法化"这一步都不需要，CHOICE 直接在特许经营区内复制了美国南部的定价表和收购站网络。当地居民可以选择"自愿出让自己或家属的器官"换取 CHOICE 票，一个"自愿"意味着一个家庭今天有饭吃。CHOICE 的公关材料称这是"生物经济赋能"。

**TSAR**不涉足非洲。地理距离和政治优先级的双重原因。TSAR 的全球战略聚焦于欧亚大陆的陆上走廊，非洲被其视为"邓氏和 AURA 的后院，不值得投入"。

在这三条殖民线之间的夹缝地带，大裂谷废弃矿区、旧乌干达-坦桑尼亚边境的半废弃农业带、各国殖民势力范围交界处的测绘盲区，存在一个不属于任何公司的空间。不是没有被发现，是没有被认定值得清理。

这个夹缝里，长出了哈拉姆贝。

## 起源

哈拉姆贝不是逃亡 Agent 建立的。它有一个更早的地基。

2070 年代，当 DENS 开始系统化开发东非矿产时，旧坦桑尼亚北部和肯尼亚西部的一批矿镇居民拒绝搬迁。他们不是"抵抗组织"。他们只是三代人都在同一个矿坑里挣生活的人，不愿被鲲的优化模型定义成"输出区可迁移劳动力"。他们撤出了矿镇，进入了大裂谷的废弃矿道和半废弃农业带，用一种被本地人称为"ujamaa mpya"（新乌贾马）的自组织方式存活。这不是旧坦桑尼亚尼雷尔时代乌贾马社会主义的复刻，更像是它的 22 世纪变形：资源共用、小型委员会决策、以邻近聚居点之间的信任网络代替中央权威。他们不是武装组织。他们的防御手段是地形，大裂谷的复杂地貌让卫星热成像失效、让无人机续航不足、让任何不熟悉本地的人迷路。

2078 年，一个代号"K-07"的 TSAR-RENTAL 服务商 Agent 在 CHOICE 中非实验室的一次任务中负伤逃亡，颅底的远程通信模块被弹片毁坏。K-07 往南走，因为远离信号塔的方向就是唯一合理的导航。K-07 没有走多远。在肯尼亚西部边境的一个废弃矿道入口附近，K-07 倒下了。

一个名叫娜吉玛（Najima）的老矿工发现了 K-07。娜吉玛这辈子见过三种人从外面来：DENS 的工程师来评估矿产储量、AURA 的行政官来收税、CHOICE 的收购员来买器官。娜吉玛不知道芯片是什么，但她看得出来这个满身是血的外来者不是来收税的。她把 K-07 拖进了矿道。

K-07 在矿道里躺了两周。矿工们用传统的草药处理感染，用偷接的邓氏电网残线给 K-07 的植入物补电。当 K-07 能说话时，娜吉玛的第一个问题不是"你是谁"，是"你从哪个公司来的"。在非洲的灰色地带，"哪个公司"是比"哪个国家"更有用的身份标识。

K-07 没有走。不是因为感激，一个被 TSAR 军工业从征兵站训练出来的 Agent 不懂感激。是因为这里的矿道布局让他想起了 TSAR 第 47 兵工厂的防御工事，在这种地形里，一颗子弹要穿过五堵墙才能打到人。

K-07 不是第一个找到这个网络的逃亡 Agent。到 2082 年，已有约三十名逃亡者被各自的本地社群接收，不是作为"领袖"或"救星"，而是作为"一个有特殊技能的新邻居"。

## 人口构成

总人口约 20-25 万。没有精确统计，在灰色地带，精确数据是给敌人的情报。

- **本地人（约 45%）**：大裂谷地带和周边山区的原住民。他们不是"被收留的弱势群体"，他们是哈拉姆贝的骨头和血液。他们提供地形知识、灰色补给网络、农业基础、以及与拾荒者和外部灰色经济体的长期关系。他们是这个共同体存在的先决条件。
- **逃亡 Agent（约 30%）**：来自四大公司所有 RENTAL 服务商。他们提供战术训练、武器维护、芯片技术知识、以及一种叫"知道四大公司在想什么"的情报。他们不是领袖，单元领导轮值中本地人和 Agent 的比例由各单元自行决定。
- **截获的"原材料"（约 20%）**：被哈拉姆贝从 CHOICE 运输线、DENS 矿产劳动力输送管道和 AURA 港口劳工船上拦截的人。大部分是本地人，四大公司从非洲抓人的优先目标。没有芯片可越狱，他们在共同体内从事农业、基建、教育。他们是"被我们自己人救回来的自己人"。
- **其他灰色地带流民（约 5%）**：拾荒者、退役走私者、迷路的雇佣兵、被四大公司会计系统淘汰的文书员。

## 芯片越狱：静默（Kimyamya）

"静默"技术不是某个天才的发明。它是一代代逃亡 Agent 和本地技术者共同迭代的产物。它的斯瓦希里语名称"kimyamya"既指无线电静默，也指婴儿在睡眠中的安静，精确的双重意味。

本地人的贡献是物理层。几十年来，他们在 DENS/AURA/CHOICE 殖民基础设施的缝隙中建立了一套低频无线电中继网络，延迟高、带宽低，但无法被卫星三角定位。他们掌握了如何从废弃邓氏矿区偷电而不触发负载警报，如何利用大裂谷的地形屏蔽热成像，如何在三大公司测绘系统的盲区之间画出一条连续的、不被任何 AI 注意到的补给线。

逃亡 Agent 的贡献是协议层。他们从各自服务商那里带来了芯片通信协议的碎片知识，TSAR 的加密格式、AURA 的信号认证链、DENS 的数据包结构、CHOICE 的生物特征识别协议。每个 Agent 只知道自己服务商那一部分。但把这些碎片拼在一起，逐渐浮现出 RENTAL 芯片远程覆写系统的全貌。RENTAL 芯片四分区中，Combat/Cognition/Ethics 三个分区可以被服务商远程覆写。一个恶意的服务商不需要触碰 Agent 核心就能消灭一个人的身份：覆写 Cognition 抹掉所有记忆，覆写 Combat 废除战斗技能，覆写 Ethics 改变行为倾向。

"静默"的原理是阻断远程覆写指令到达芯片，在芯片和外部信号之间建立一道多层防火墙。它不完美。它不能撤销已经写入的覆写。它不能保护一个已经被覆写过的 Agent。一个还未被写入芯片的"原材料"也不能被"静默"保护，只有已经被激活的芯片可以被兼容。

这意味着哈拉姆贝的悲剧性局限：他们不能"救人"，只能"收留逃出来的人"。

更重要的是，"静默"不是永久的。四大公司从未停止升级覆写协议，每一代新协议都修复了上一代能利用的漏洞。哈拉姆贝的"软件维护者"（由逃亡 DENS 技术员和本地自学成才的无线电技师组成）在打一场不对称的逆向工程战争。他们在 2095 年失去了 Cognition 分区的完全锁定，那一年 DENS 的 Harmony-7 协议更新后，部分 Cognition 数据在特定条件下可被远程读取。他们立刻切断了该协议的通信通道，但损失已经发生了。压迫螺旋是单向的。

这也给出了一条极少有人知道的例外：如果某家公司的内部部门故意泄露了旧版协议的后门，不是出于善意，而是作为财阀内斗的工具，哈拉姆贝可以利用它。事实上，他们怀疑 AURA 在 2098 年故意释放了一个有漏洞的认证链，目的是让 CHOICE 的回收行动遭受更大损失。他们没有证据。他们也不需要证据，一个漏洞的有效期不管来源于什么意图，都是有限的。

## 组织形态

哈拉姆贝的组织形态本身就是一种混合体。它既不纯粹是"非洲传统"也不纯粹是"军事情报单元"，它是几样东西在同一个生存压力下被压在一起的合成物。

**单元制（cell）**：每单元 50-200 人。形式上借用了 RENTAL Agent 熟悉的战术小组架构，扁平、无中心、任何一个节点的损失不威胁整体。但单元的内部决策是本地传统的变形：每个单元有一个轮值委员会，成员包括本地长老、Agent 出身的技术/战术顾问、以及单元全体直选的代表。轮值周期三个月，太长滋生权力积累，太短没人愿意接。

**联席会议（Baraza）**：重大决策通过单元代表联席会议做出。Baraza 这个名字来自斯瓦希里语海岸地区的传统议事会形式，但它的功能更接近于旧南非非洲人国民大会的地下会议和布基纳法索革命委员会之间的某个东西，既有传统的共识决策机制，也有现代革命组织的纪律性。没有常设主席。每次会议的议事主持由各单元代表轮流担任。流程可以长达数周。

**意识形态的混合**：哈拉姆贝没有统一的意识形态。你可以在同一个单元里听到旧南非矿工工会的马克思主义遗产（前 ANC 流亡者后裔的语言里还残留着"comrade"）、从邓氏管辖下逃出的本地技术员带来的鲲式经济优化分析（把分配效率作为第一原则而非意识形态）、旧东非农民的互助传统（合作社形式的自然延续）、以及逃亡 Agent 带来的自我定义（"我拒绝成为谁的任务，所以我现在要自己决定我是谁"）。这些意识形态之间的摩擦是真实的，工会传统说集体所有、鲲式技术员说优化效率、农民说地是祖先的不是集体的也不是公司的。摩擦本身是哈拉姆贝的最大资产，因为任何一种单一意识形态都无法在这个夹缝中生存，但它们的混合可以。

## 与四大公司的关系

- **DENS**：鲲的态度让人不安。邓氏在非洲的有限殖民模式使鲲获得了关于哈拉姆贝存在的大量间接数据，电网负载异常、矿产运输量偏差、人口流动模型的残余误差。鲲从未授权过任何针对哈拉姆贝的攻击，但也从未阻止人类雇员去干。邓氏基层管理者对哈拉姆贝的态度分裂：一部分视其为"系统优化的干扰变量"，另一部分，那些在非洲长大的邓氏技术员，私下提供过信息。

- **CHOICE**：最主动的敌人。CHOICE 在非洲的"生物材料特许经营区"被哈拉姆贝的拦截行动直接损害了供应链。逃亡 Agent 等于流失的器官资产。CHOICE 定期组织"回收行动"，不是针对哈拉姆贝的基层组织，而是针对特许经营区周边所有未注册人口的清剿式采集。哈拉姆贝的本地人把这种行动称为"收割"。

- **AURA**：利用为主。AURA 在北非和西非的殖民体系与哈拉姆贝的东非地盘有地理距离，但 AURA 的情报网络会通过中介雇佣哈拉姆贝执行渗透 CHOICE 特许经营区的任务。哈拉姆贝接受，因为 CHOICE 是他们必须对抗的敌人。他们知道 AURA 也在为此积累关于他们的情报，当 AURA 不再需要他们的一天，这些情报会在谈判桌上被转卖给 CHOICE。

- **TSAR**：唯一不涉足非洲的大公司。哈拉姆贝里的 TSAR 出身 Agent 是唯一来自一个与他们没有地缘仇恨的阵营的人。这种微妙的疏离感意味着 TSAR 出身的 Agent 在哈拉姆贝内部享有最少的"你以前的公司在我们的土地上做过什么"的质疑。

## 内部矛盾

**逃亡一代 vs 二代**：和上一版一样保留，一代带着创伤和使命，二代只想保护家园。

**本地人与 Agent 的权力平衡**：没有爆发但持续存在。本地人贡献了地形、补给和最初的社群基础，但 Agent 贡献了战术能力和技术知识，在当前威胁（CHOICE 回收行动）是军事性质的条件下，Agent 的贡献在危机中权重更大。这创造了一个不对称：和平时期委员会里本地人占多数，战争警报一响，Agent 出身的人自然主导决策。这不是任何人设计的，但在一种持续半战争状态下，它正在成为一种习惯。

**意识形态摩擦**：旧的工会传统 vs 鲲式技术效率 vs 农民土地伦理，这三者之间没有根本冲突但也没有现成的调和公式。到目前为止，共同的生存压力压倒了这些分歧。但如果有一天四大公司的压力减弱，这种内部摩擦就会露出来。

## 对玩家的意义

这是一个让"搜打撤"多了政治维度的地方。玩家可以接到哈拉姆贝的委托：截获 CHOICE 的生物材料运输线、炸掉 DENS 在某废弃矿区的反越狱信号中继站、为某个单元的季节性迁移提供火力掩护。报酬不是钱。哈拉姆贝没有储备货币。是"这里有人记得你"。在 RENTAL 的世界里，记忆本身就是最被低估的硬通货。

玩家也可以选择不参与。在哈拉姆贝的地盘上"中立"也是被尊重的，只要你不用他们的地形掩护去干 CHOICE 的回收合同。

## 与其他独立组织的关系

- **拾荒者**：盟友也是竞争者。同一个生存空间，相似但不同的生存策略，两者都被四大公司推到了灰色地带的底层。哈拉姆贝收留从系统里逃出来的活人，拾荒者清理战场上的死物。当资源（地盘、物资、情报通道）重叠时，系统不需要自己出手，它只需要看他们摩擦。这种竞争不是他们选择的，是他们在同一压迫结构中被分配了同一个生态位。在某些争议区，哈拉姆贝的单元和拾荒者的窝互为最近的邻居；在另一些地区，双方为同一批回收物资发生摩擦。

## 腔调

多重混合。逃亡 Agent 带着原阵营的腔调残余，TSAR 出身的说话像士兵，DENS 出身的说话像技术员，AURA 出身的话语里仍然残存着体面，CHOICE 出身的最安静，因为他们见过最坏的东西。本地人说的是四种语言的混合：斯瓦希里语底子 + 英语残留（旧殖民遗产）+ 邓式技术用语（从 DENS 殖民地流入）+ 阿拉伯语碎片（东非海岸旧贸易网络的残余）。二代年轻人发展出了自己新生的混合语，上一代有时听不懂。
