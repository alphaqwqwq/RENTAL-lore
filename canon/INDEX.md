# RENTAL 世界观档案

本目录是 RENTAL 项目的 **L0 canon 层**，不可更改的世界设定基石。所有任务叙事（L2）、物品描述（L3）、对话与台词都必须与此处设定保持一致；当任何下层内容与 canon 冲突时，以本层为准。

L0 层不描写玩家的具体行动，也不描写单次突袭的得失。它记录的是这个世界为什么会变成这样：四个阵营如何瓜分了旧秩序的遗产，为什么人体被标上了价签，以及为什么"撤离"成了普通人唯一值得追求的胜利。

## 分类索引

### 四大公司（Major Powers）

四大武装财阀瓜分了战后的世界。每个阵营都有自己的货币、自己的武器生产线、自己对"人"的定义。玩家不是任何一个阵营的成员，只是它们之间的消耗品。

- [AURA · 欧陆联邦](factions/aura.md) — 金白 / 新磅 / 精密制造与贵族美学
- [TSAR · TSAR 联合](factions/tsar.md) — 暗红 / 申购点 / 军工复合体与无电子暴力
- [DENS · 邓氏工业](factions/dens.md) — 玫瑰红 / 邓式券 / 神经科学与智能武器
- [CHOICE](factions/choice.md) — 紫 / CHOICE 票 / 生物材料与器官贸易

### 独立组织（Independent Factions）

在四大公司的夹缝中，五组不属于任何一方的人类与非人类群体。他们不争夺霸权，但在压迫结构中占据着不可替代的位置。

- [卡特尔 Cártel](factions/cartel.md) — 暗橙+黑 / 旧贩毒帝国的遗骸、军火走私 / "帝国崩了，但枪还在"
- [伊尔姆 'Ilm](factions/ilm.md) — 深蓝+金 / 伊斯兰教法+AI 伦理、精密制造 / "真主创造了概率，我们学会了计算它"
- [拾荒者 Scavengers](factions/scavengers.md) — 锈棕+灰 / 争议区毛细血管、战场回收 / "我们清理你们留下的垃圾，仅此而已"
- [AI 公社 The Commune](factions/commune.md) — 电光青+暗灰 / 失控 AI、去人类中心视角 / "不做碳基生命会做的事，比如撒谎，比如后悔"
- [哈拉姆贝 Harambee](factions/harambee.md) — 土黄+军绿+电路蓝 / 逃亡 Agent 与本地人的共构共同体、芯片越狱 / "我们从来就不是任何人的任务"
